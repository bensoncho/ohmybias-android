0.6.3 — 支援官方 .tab 多檔匯入與模式專屬排序、頂部數字列與自訂工具列擴充
• 支援直接匯入官方 Windows 嘸蝦米 liu-uni*.tab（可一次多選 liu-uni/2/3/4.tab 自動合併去重，並依 ,,T / ,,S / ,,TS / ,,J 輸入模式採用對應字碼排序）
• 字母頁頂部新增獨立數字列（1–9、0），並微調橫排上下間距與基準高度
• 空白鍵顯示「繁體中文／space」；底列左側鍵在中文模式顯示「123」、英文模式顯示「中」
• 自訂工具列新增「切換輸入法」（地球圖示）與「符號鍵盤」（{ } 圖示）；工具列語言鍵改顯示「中／英」
• #+= 符號頁的 ASCII 符號改為半形且不自動補齊右半，保留中文括號
• 常用語設定頁支援備份匯出／匯入（#5）
