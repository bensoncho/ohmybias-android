# OhMyBias 米 Android

Android 嘸蝦米（Boshiamy）鍵盤 — [ohmybias-ios](https://github.com/plateaukao/ohmybias-ios) 的 Android 移植版
（引擎層一對一對應，源自 [Yabomish](https://github.com/plateaukao/yabomish)）。
純 Kotlin、零第三方執行期依賴。

## 特色

### 輸入引擎

- **嘸蝦米輸入**：支援匯入自己的 `liu.cin` 或官方 Windows 嘸蝦米 `liu-uni*.tab`（可一次多選 `liu-uni.tab`、`liu-uni2.tab`、`liu-uni3.tab`、`liu-uni4.tab` 自動合併去重，並依 `,,T`／`,,S`／`,,TS`／`,,J` 輸入模式各自建立專屬排序字表），on-device 編譯 mmap 零拷貝載入（CINM 格式與 iOS 版相同，檔案可互通）
- **基本聯想詞**：commit 後即出現詞組聯想（萌典詞組，CC0，僅 687KB）＋自訂詞（user_phrases.txt）；聯想列開頭有 ✕ 可一鍵關閉
- **`,,` 指令**：`,,T/S/J` 切模式、`,,ZH` 注音查碼、`,,TO` 同音字、`,,PYS/PYT` 拼音查碼、`,,SG` 聯想開關、`,,PIN` 固定同碼字排序、`,,V/VT/VS` 剪貼簿（ICU 簡繁轉換）、`,,H` 說明
- **極簡資料**：不含專業詞典／語料 binary（<2MB）

### 鍵盤介面（以 sweetlime 皮膚為藍本，與 iOS 版一致）

- **滑動手勢**：鍵帽角標提示 — 上滑出符號、下滑出數字；`n`/`m` 次選、三選直接上屏；空白上滑切中英、水平拖曳移動游標；Enter 上滑跳注音頁；`z`/`m` 下滑句首句尾、`v` 下滑貼上
- **英文大寫鎖定（Caps Lock `⇪`）**：英文輸入模式下，連按兩下或長按 Shift 啟用大寫鎖定（`⇪`），再按 Shift 解除；單按仍只大寫一字，切換中英輸入模式時自動重設
- **長按選單**：字母大小寫／變音變體、逗號句號長按插入日期時間（中文／民國／日本／英文／農曆／時區，android.icu 曆法）
- **多筆剪貼簿面板與快速貼上提示**：工具列剪貼簿開啟多筆剪貼簿面板（自動分類「全部／地址／電話／網站／電子郵件」，支援釘選 📌、一鍵清除未釘選 🗑️ 與單筆動作選單）；當剪貼簿有新複製且尚未貼上過的文字時，工具列自動彈出第一筆快速貼上膠囊，點擊直接貼上並自動收起
- **工具列與面板**：設定、♥ 常用語面板、符號／Emoji／顏文字分類面板、剪貼簿面板、**符號鍵盤**（`{ }` 圖示，一鍵直達 `#+=` 符號頁，再按切回）、**切換輸入法**（地球圖示，切換系統輸入法）、語言鍵顯示目前模式（中／英）、游標左右、收折、**浮動鍵盤**（鍵盤浮在畫面上，底部把手拖曳移動、四角縮放，再按一次停回底部）；cskin 可配置的編輯按鈕全支援 — 全選（自動喚起 Android 系統原生浮動選取選單，支援網址辨識開啟、AI、剪下、複製、貼上、翻譯）／複製／剪下／復原／重做／簡繁切換（iOS 版因 extension API 缺失無法支援的部分，Android 依原始定義實作）。設定頁「主題 ▸ 自訂工具列」可直接在手機上排 10 格
- **多頁鍵盤**：字母（頂部含獨立數字列 `1–9、0`；空白鍵顯示「繁體中文」／「space」；底列左側在中文模式顯示 `123` 切數字頁、英文模式顯示 `中` 切回中文）、九宮格數字、Row 數字半形符號、`#+=` 符號頁（半形 ASCII 符號 `[ ] { } # % ^ * + = _ \ | ~ < > &` 與中文括號，半形符號不自動補右半）、注音查碼
- **主題**：淺色／深色調色盤；可匯入 `.cskin` 皮膚設定（工具列、調色盤、字級、版面選項）
- **記住中英模式**：鍵盤重啟後還原上次輸入模式
- **常用語組字碼**：常用語設定頁可為每句設自訂組字碼，直接打碼叫出、不必開 ♥ 面板；碼已被字表使用時本句排在既有候選之後（設定時即時提示）。密碼類欄位自動暫切英文直通
- **鍵盤高度調整**：設定頁滑桿 85–140%（鍵面字級連動放大，上限 1.2×）— 大螢幕手機可調大

## 安裝

1. `./gradlew assembleDebug` 後安裝 `app/build/outputs/apk/debug/app-debug.apk`
2. 開 OhMyBias 米 app → 匯入 `liu.cin`
3. 系統設定 → 螢幕鍵盤 → 啟用「OhMyBias 米」，並切換為目前輸入法

> ⚠️ `liu.cin` 為行易公司版權字表，請自備，本專案不含亦不得散布。

## 開發

```bash
./gradlew assembleDebug        # 建置 APK
./gradlew testDebugUnitTest    # 引擎測試（JVM，無需模擬器）
```

## 專案結構

```
app/src/main/java/info/plateaukao/ohmybias/
  shared/      # 平台無關引擎（對應 iOS Shared/；禁止 Android API）
  keyboard/    # IME service、鍵盤五頁、候選列、面板、主題、手勢
  android/     # SharedPreferences、剪貼簿（ICU）、Application
  MainActivity # 設定頁（匯入字表/皮膚、偏好、自訂詞、測試輸入）
app/src/main/assets/   # phrases.bin（萌典）、s2t/t2s、zhuyin/pinyin/char_freq（mmap 二進位）
tools/                 # 資料檔產生腳本（JSON → mmap 二進位）
app/src/test/          # JUnit 引擎測試（移植自 iOS Tests/）
```

## 版本紀錄

### v0.6.3
- **字母鍵盤新增頂部數字列（`1–9、0`）**：於 `qwertyuiop` 上方加入獨立數字排，並適度拉開橫排上下間距（`7.5dp`）與基準高度（`250dp`），不必切換鍵盤即可直接輸入數字
- **地球鍵（`🌐`）改為切換中／英文輸入**：點按底列 `🌐` 鍵直接切換嘸蝦米／英文模式（長按工具列「米／英」仍可叫出系統輸入法選單）
- **工具列新增「符號鍵盤」按鈕（`{ }`）**：可在「設定 ▸ 主題 ▸ 自訂工具列」加入，點一下直接切換至 `#+=` 符號輸入頁面，再點一次切回原頁面
- **底列與空白鍵標示優化**：中文模式空白鍵顯示「繁體中文」、左側鍵顯示 `123`（切至數字鍵盤）；英文模式空白鍵顯示「space」、左側鍵顯示 `中`（切回中文輸入），均套用一般按鍵模板
- **工具列新增「切換輸入法」（地球圖示）與「符號鍵盤」（`{ }` 圖示）**：可在「設定 ▸ 主題 ▸ 自訂工具列」配置；工具列語言鍵標示由「米」改為「中」，並移除設定頁「隱藏 🌐 鍵」選項
- **`#+=` 符號頁改為半形**：將原本的全形 ASCII 符號（`[ ] { } # % ^ * + = _ \ | ~ < > &`）改為半形，並保留中文專屬括號（`《 》 『 』 【 】 〈 〉 ・`）
- **半形括號／引號不自動補齊**：輸入 `(`、`[`、`{`、`"` 時不再自動補上右括號或引號；「成對標點自動補右半」僅套用於中文成對標點（`「`、`（`、`『`、`【`、`《`、`〈`）
- **英文大寫鎖定（Caps Lock `⇪`）**：英文模式下連按兩下或長按 Shift 啟用大寫鎖定（顯示 `⇪`），再按一次 Shift 解除；單按維持首字大寫，切換中英模式時自動重設
- **多筆剪貼簿面板與快速貼上膠囊**：
  - 點擊工具列剪貼簿按鈕展開多筆剪貼簿面板，支援「全部／地址／電話／網站／電子郵件」智慧分類、釘選常駐（📌）、清除未釘選（🗑️）及單筆卡片選單
  - 剪貼簿有新文字且尚未貼上過時，工具列自動彈出第一筆快速貼上膠囊，點擊即可一鍵貼上並收起提示
- **工具列「全選」喚起系統原生選單**：點擊工具列「全選」後自動選取全文並喚起 Android 系統原生浮動選取選單（含網址智慧辨識「開啟」、AI、剪下、複製、貼上、翻譯與雙水滴控點）
- **全新科技蝦米 App 圖示**：更新 App 圖示與 Adaptive Icon 為專屬無外框科技感蝦米與發光鍵盤設計，搭配深藍青漸層背景
